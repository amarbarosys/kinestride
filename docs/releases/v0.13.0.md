# kinestride v0.13.0

**Released:** 2026-10-26 · **Commit:** `7209cf9` · **Previous:** [v0.12.1](v0.12.1.md)

## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
65,536 articulated bodies, each with 74 degrees of freedom, contacts and 50 actuators, step together in 66.7 ms
on one AMD RX 7900 XTX. Kinestride is batched GPU physics in Mojo: one GPU thread per body, any MuJoCo MJCF model
as input, and every stage checked against MuJoCo 3.9.0 with a planted bug that the check must catch.

## Highlights

- Game NPCs can now think with npc-mind brains and move with physical bodies: 8 of a world's 100 NPCs walk as spiders,
  driven by the scripted schedule or the imitated npc-mind base brain, and the world sees where each body really is.
- Bodies follow the brain's moves 93 to 97 % of ticks, and having a body costs the NPCs no measurable need satisfaction
  (200 ticks, 3 seeds).
- One embodied world uses 184 MB of host memory, not 1.58 GB.

## Known limits

<!-- Honest list: slow paths, unsupported cases, flaky upstreams, anything UNVERIFIED. -->
- 8 bodies per world; ~1.7 s wall per 0.8 s tick on the host engine (physics dominates).
- Facing is quantized to N/E/S/W; trees and walls exist only in the world, not as physics.
- npc-mind comes from a pinned worktree (`NPC_MIND`); its world.mojo is linked as `npc_world` (kinestride has a world.mojo).
- Learning arms (owned, TD) on bodies and live rendering are not built.
- Imitation accuracy depends on how many seeds are batched (seed 0: 0.548 alone, 0.597 with 3).
