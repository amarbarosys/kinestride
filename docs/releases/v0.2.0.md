# kinestride v0.2.0

## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
65,536 articulated bodies, each with 74 degrees of freedom, contacts and 50 actuators, step together in 66.7 ms
on one AMD RX 7900 XTX. Kinestride is batched GPU physics in Mojo: one GPU thread per body, any MuJoCo MJCF model
as input, and every stage checked against MuJoCo 3.9.0 with a planted bug that the check must catch.

## Highlights

- Bodies look solid: smooth shading, sun shadows on the ground and on each other, soft contact darkening where
  legs meet bodies and ground, smooth silhouettes.
- Costs about 1 % of a live frame (fly + spider on terrain: 78.2 -> 79.0 ms with K=10 physics).

## Changes

### Added
- Shadow map: the scene rastered again from a near-orthographic sun camera (`suncam`), 3x3 PCF (`SHADOW=2`,
  default); `SHADOW=1` a soft blob per animal for crowds; terrain self-shadow with `TERRAIN=1`.
- Smooth normals: `meshes()` appends area-weighted vertex normals to `rv.bin`; thin two-sided parts keep face normals.
- Screen-space ambient occlusion from the visibility buffer; edge anti-aliasing (`AA=1`, 4 analytic sub-rays on
  silhouette pixels).
- `render.frame()` runs one frame's passes; `kinestride/render_look.py` renders and times N flies.
### Changed
- Lighting in linear light (gamma 2): sun at 57 degrees, sky/ground ambient, highlight on animals, sky gradient;
  fog stays on the ground only.
- `rv.bin` is 12 bytes per vertex (was 6) and `shade()` takes the shadow map: callers load `12 * NRV` bytes and
  run frames through `render.frame` (fly-connectome `live.mojo` does, `6a7f4b4`).

## Known limits

- The shadow map has the view's size (16.6 MB at 1080p) and covers 1.5 view distances around the target;
  shadows farther out are not drawn.
- `SHADOW=1` loops over every animal per ground pixel: for small F only.
- SSAO and blob radii are in mm (fly scale); bodies in other units need other constants.
- Small dark specks at some leg joints were there before this release too.

## Upgrade / run

```
python -m kinestride.render_look OUT 1        # under gpu-wait: a close-up frame and its ms
# callers of render.shade: load rv.bin as 12 * NRV bytes, allocate NSM uint64 + NCAM floats, use render.frame
```
