# kinestride v0.9.0

**Released:** 2026-10-12 · **Commit:** `b4c913a` · **Previous:** [v0.8.0](v0.8.0.md)

## What it does

65,536 articulated bodies, each with 74 degrees of freedom, contacts and 50 actuators, step together in 66.7 ms
on one AMD RX 7900 XTX. Kinestride is batched GPU physics in Mojo: one GPU thread per body, any MuJoCo MJCF model
as input, and every stage checked against MuJoCo 3.9.0 with a planted bug that the check must catch.

## Highlights

- Watch any exported body live: `view.mojo` runs the engine and the renderer in one process, ctrl held, frames to
  stdout for mpv or the last frame to a file. An app with its own controller builds on `viewer.Viewer` (fly-connectome's
  brains now do).

## Known limits

- No window or input here: a game needs its own (fly-connectome's comes from mojo-imkit).
- The plan's `Controller` trait was not built: each app keeps its own loop around `step` and `frame`.
- Checked on one GPU (RX 7900 XTX).

## Upgrade / run

```
python -m kinestride.view_check build 10
gpu-wait run --timeout 900 -- kinestride/check.sh view
view DIR/ 0 0 -18 6 0 0 1 40 | mpv --demuxer=rawvideo --demuxer-rawvideo-w=960 --demuxer-rawvideo-h=540 --demuxer-rawvideo-mp-format=rgba -
```
