## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
65,536 articulated bodies, each with 74 degrees of freedom, contacts and 50 actuators, step together in 66.7 ms
on one AMD RX 7900 XTX. Kinestride is batched GPU physics in Mojo: one GPU thread per body, any MuJoCo MJCF model
as input, and every stage checked against MuJoCo 3.9.0 with a planted bug that the check must catch.

## Highlights

- A motion dataset in one launch: every animal plays its own clip, can be pushed, and falls as real physics once its
  assist is released; poses, solver contacts and a labels table (clip, CMU description, push, fell) come out.
- 746k animal-steps/s at 16,384 animals (178x the first tracking loop), matching MuJoCo's run of the same schedule
  to 1.5e-7 m through every push.
- Per-animal equality on/off (`-DEQACT=1`), MuJoCo's eq_active, checked against MuJoCo.
- The gates hold the GPU only for engine runs: kernels compile beforehand in gpu-wait's CPU room.

## Changes

### Added
- `-DEQACT=1`: one ctrl.bin row per equality after the push slots (`docs/API.md`); `check.sh eqact`.
- `check.sh dataset`; `track_check prepare DIR FLIES SCHEDULE STEM...` (per-animal ref.bin and plan.bin).
- `track` env: `NOWRITE=1` (throughput), `COMPILE_ONLY=1` (fill the kernel cache and exit).
### Changed
- `track DIR` reads per-animal inputs and writes every animal to `DIR/out.bin`; built with `-DNXF=1 -DEQACT=1`.
- `check.sh track` / `dataset` run on the CPU and put only the engine binary through gpu-wait; warm with `BUILD_ONLY=1`.

## Known limits

- After a fall starts, Kinestride and MuJoCo diverge (contact-rich chaos); only the frames through push + 10 are barred.
- Without the assist the servos do not balance: an unpushed animal with the assist off falls too. Balance control is open.
- Writing every animal's poses is 2 GB per 800 frames at 4,096 animals; NOWRITE measures the loop alone.
- The 16,384-animal rate is one 60-frame run.
- Checked on one GPU (RX 7900 XTX).
