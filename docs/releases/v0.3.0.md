# kinestride v0.3.0

## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
65,536 articulated bodies, each with 74 degrees of freedom, contacts and 50 actuators, step together in 66.7 ms
on one AMD RX 7900 XTX. Kinestride is batched GPU physics in Mojo: one GPU thread per body, any MuJoCo MJCF model
as input, and every stage checked against MuJoCo 3.9.0 with a planted bug that the check must catch.

## Highlights

- The fly looks like MuJoCo's: textured golden-brown body, see-through wings, reflections on the floor, the arena drawn.
- Several brain-driven flies render smoothly: world parts are drawn once (fly-connectome's CPU physics now runs animals in
  parallel: 5 flies 62 fps instead of 8.5).
- Models of any size: the visibility key gives the triangle field the bits the model needs.

## Changes

### Added
- Texture colours per vertex (`meshes`: MuJoCo cube textures sampled by direction, 5x5 mip level); rv.bin carries rgb,
  `RVI` = 9 int16 per vertex for callers.
- `GLASS`: parts with alpha < 1 in their own layer, blended at their alpha. `REFLECT`: the opaque scene mirrored in z = 0,
  mixed into a flat floor at 0.2.
- `kinestride/assets.py`: the mesh builders `meshes(world=...)` uses (they had stayed in fly-connectome).
### Changed
- `raster(..., base, mode)`: one kernel draws the view, the shadow map, the glass and the mirror layers; `NSM` is the aux
  layers' sum (callers allocate by it). Keys: animal << TB | triangle, TB sized to `NTRI`.
- World parts (body 0) are rastered once, not once per animal.
- `render_check` draws the arena's box geoms; alpha marks animal parts only.
### Fixed
- `meshes(world=...)` imported `kinestride.assets`, which did not exist here.
- `tools/doclinks.sh` resolves a bare name to any tracked file of that name.

## Known limits

- The floor is Kinestride's grey checker, not MuJoCo's dark grid material.
- Glass ignores animals behind a wing (it blends over the opaque layer only); the mirror is for a flat floor (off on
  terrain and in the cube) and is unshadowed.
- Every aux layer has the view's size: 16.6 MB each at 1080p.
- 960 x 540 frame 0.72 -> 1.15 ms with glass, mirror and the arena's 249k triangles.

## Upgrade / run

```
callers of render.mojo: load rv.bin as 2 * RVI * NRV bytes, allocate NSM uint64 for the aux buffer, run render.frame
env MUJOCO_GL=egl python -m kinestride.render_check OUT    # under gpu-wait: our render beside MuJoCo's
```
