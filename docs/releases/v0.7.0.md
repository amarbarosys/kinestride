# kinestride v0.7.0

**Released:** 2026-10-12 · **Commit:** `c480d4c` · **Previous:** [v0.6.0](v0.6.0.md)

## What it does

65,536 articulated bodies, each with 74 degrees of freedom, contacts and 50 actuators, step together in 66.7 ms
on one AMD RX 7900 XTX. Kinestride is batched GPU physics in Mojo: one GPU thread per body, any MuJoCo MJCF model
as input, and every stage checked against MuJoCo 3.9.0 with a planted bug that the check must catch.

## Highlights

- Two mesh bodies can touch: mesh-vs-mesh contact (MuJoCo's mjc_Convex, up to 5 contacts per pair), exact against
  MuJoCo in float64 on 6000 random fly-hull poses, across trees too, so a fly's leg and a spider's leg collide.

## Changes

### Added
- Mesh-mesh pairs with `convex`; `check.sh meshmesh`; fixture `models/cross_mesh.xml`; `convex_check mesh`.
### Fixed
- Export refuses box-mesh and mesh-mesh pairs at margin 0 (MuJoCo takes a polygon-clipping path there that is not
  ported; such a model used to export and disagree silently).

## Known limits

- Every potential pair is in the model's static Hessian pattern. Fly + spider with 480 tarsus pairs: 36.5 -> 271.6 ms per
  launch at 1,024 animals with no leg touching (NH 1,501 -> 7,847), and out of memory at 65,536. List few pairs, or wait
  for dynamic pairs.
- Margin 0 box-mesh and mesh-mesh pairs are refused (native polygon clipping not ported).
- Checked on one GPU (RX 7900 XTX).

## Upgrade / run

```
gpu-wait run --timeout 3600 -- kinestride/check.sh meshmesh
```
Mesh-mesh pairs need `margin` > 0 on the `<pair>` and an export with `convex=True` (`CONVEX=1` in check).
