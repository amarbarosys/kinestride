# kinestride v0.14.0

**Released:** 2026-11-18 · **Commit:** tag `v0.14.0` · **Previous:** [v0.13.0](v0.13.0.md)

## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
65,536 articulated bodies, each with 74 degrees of freedom, contacts and 50 actuators, step together in 66.7 ms
on one AMD RX 7900 XTX. Kinestride is batched GPU physics in Mojo: one GPU thread per body, any MuJoCo MJCF model
as input, and every stage checked against MuJoCo 3.9.0 with a planted bug that the check must catch.

## Highlights

- First public release: README, docs/CAPABILITIES.md, docs/VS_MUJOCO.md, docs/HISTORY.md, agent skill in skills/, Apache-2.0.

- Godot route A: the engine as a GDExtension (C ABI, KinestrideWorld/NpcMind classes, crowd scenes).

## Known limits

- Only gfx1100 (RX 7900 XTX) has run the engine.
- At 1,024 animals MuJoCo on the CPU is faster (0.65x); the crossover lies between 1,024 and 16,384, not measured.
- cone_hfield stage red; noslip after PGS+convex refused.
- Fly and flight test bodies come from fly-connectome; flight needs flybody assets (tools/fetch_flybody.sh) and a wing pattern file not yet shipped.
- MuJoCo comparison figure (70,582 steps/s, six CPU workers) dates from 2026-10-02, not re-run.

## Upgrade / run

```
uv sync
tools/smoke.sh
tools/assets.sh ~/path/to/fly-connectome   # test bodies
kinestride/check.sh step
```
