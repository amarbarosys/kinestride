## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
65,536 articulated bodies, each with 74 degrees of freedom, contacts and 50 actuators, step together in 66.7 ms
on one AMD RX 7900 XTX. Kinestride is batched GPU physics in Mojo: one GPU thread per body, any MuJoCo MJCF model
as input, and every stage checked against MuJoCo 3.9.0 with a planted bug that the check must catch.

## Highlights

- Any mocap skeleton drives one character: CMU or Mixamo-style BVH (any units, extra twist bones, split spines)
  retarget onto one 21-body, 70 kg body, so every clip uses the same model and can share one engine binary.
- Cleaner references: isolated mocap spikes repaired with zero lag, and feet held exactly still while in contact
  (ankle drift 0.7-0.8 mm/frame mean, 8 mm max -> 0.0002 mm).
- 112-146x Godot 4.7.2's RetargetModifier3D on the same machine (2.8-3.65M frames/s), in 527 lines of Mojo against
  Godot's 5,998 for its modifier set; ideas observed, rebuilt clean-room.

## Changes

### Added
- Canonical profile and retarget in `bvh.mojo`; spike repair (`REPAIR`, `CAP`); limb planting (`PLANT`, `BLEND`, `HANDZ`).
- `tools/bvh_variant.py` (Mixamo-style rewrite for the round trip), `tools/godot_bench.gd` (Godot baseline),
  `docs/provenance/motion-godot.md`.
### Changed
- `bvh mjcf OUT.xml` takes no clip: one character for every clip. `.qref` rows are the 21-body character (NQ 67).
- `check.sh bvh` checks the retarget against a numpy twin, a round trip, repair and planting (14 mutants).

## Known limits

- Limb planting is 24x Godot's TwoBoneIK3D, short of the 100x target set before building.
- The root assist still does much of the balancing; servo-only balance is open.
- Clips must be at the character's rate (HZ, default 120); no resampling yet.
- Hands plant only below HANDZ: no CMU clip here puts a hand on the floor, so the arm path is checked with HANDZ=2.
- Checked on one GPU (RX 7900 XTX).
