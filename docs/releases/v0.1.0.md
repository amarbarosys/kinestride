# kinestride v0.1.0

**Released:** 2026-10-09 · **Commit:** `3248a3f` · **Previous:** first release

## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
65,536 articulated bodies, each with 74 degrees of freedom, contacts and 50 actuators, step together in 66.7 ms
on one AMD RX 7900 XTX. Kinestride is batched GPU physics in Mojo: one GPU thread per body, any MuJoCo MJCF model
as input, and every stage checked against MuJoCo 3.9.0 with a planted bug that the check must catch.

## Highlights

- First release as its own repo, split from fly-connectome: a fresh checkout builds and smoke-tests without
  any fly-connectome path.
- All 35 `check.sh` stages proven from this repo, each with its planted bugs caught.
- The full merge gate holds the GPU about 18x shorter: planted-bug binaries are built on the CPU first.

## Changes

### Added
- `tools/smoke.sh`: CPU-only check (doc links, export, full-step build), 28.5 s cold, 0.25 s warm.
- `tools/doclinks.sh`: every .md a tracked file names must exist.
- `tools/blender_check.sh`: a Blender rig through blender-mjcf into `check step`.
- `.claude/skills/body-engine` (moved from fly-connectome), `docs/CONVEX_CONTACT.md` (moved).
### Changed
- `tools/check_all.sh`: QUICK=0 builds every mutant on the CPU, one at a time (gravcomp GPU hold 103.2 s -> 5.6 s).
- `tools/assets.sh` no longer copies MuJoCo sources (`mj-port source` fetches them on demand).
- Docs: `ENGINE.md`, `ENGINE_OPT.md` (renamed), history moved to Brain, no dangling links; probes moved to `probes/`.
- `check()` skips the stale qH / qHDiagInv rows for Euler with no dof damping (MuJoCo leaves them 0).
### Fixed
- Hard-coded `/home/<user>` paths in `tools/flight_export.py`, `convex_check.py`, `hfield_check.py`; test-body
  defaults resolve against the repo root.
- QUICK=0 parallel builds could cache a planted-bug binary under a clean source key (mutant-check edits sources
  in place while mojo-cached hashes them first).

## Known limits

- Only run on gfx1100 (RX 7900 XTX).
- `541cef7` (check() qH skip for Euler with zero dof damping) and `3248a3f` (blender_check) landed after the full
  run: no kernel source changed, but the narrowed check() comparison is not covered by the 21-stage run.
- Full implicit costs 85 KB of scratch per body (5.6 GB at 65,536 bodies): not a crowd mode yet.
- The live viewer still lives in fly-connectome.

## Upgrade / run

```
uv pip install -e ~/Projects/mojo/kinestride      # Python: kinestride.model
tools/smoke.sh                                    # CPU, no assets
tools/assets.sh && QUICK=0 tools/check_all.sh     # full gate (gpu-wait inside)
```
