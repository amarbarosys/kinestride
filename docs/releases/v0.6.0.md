# kinestride v0.6.0

**Released:** 2026-10-12 · **Commit:** `6056e0c` · **Previous:** [v0.5.0](v0.5.0.md)

## What it does

65,536 articulated bodies, each with 74 degrees of freedom, contacts and 50 actuators, step together in 66.7 ms
on one AMD RX 7900 XTX. Kinestride is batched GPU physics in Mojo: one GPU thread per body, any MuJoCo MJCF model
as input, and every stage checked against MuJoCo 3.9.0 with a planted bug that the check must catch.

## Highlights

- Push any body: a force and torque per slot (MuJoCo xfrc_applied) move the body as MuJoCo does; for hits,
  explosions, grabbing and dragging with the mouse.
- `docs/API.md` names the stable surface: the model tables, the per-animal rows (incl. push slots) and the step.

## Known limits

- Push input is checked with the Euler integrator; RK4 and implicit read the same sum but have no xfrc gate.
- Slots are sparse and fixed per build (NXF); a body id of 0 leaves a slot empty.
- Checked on one GPU (RX 7900 XTX).

## Upgrade / run

```
gpu-wait run --timeout 3600 -- kinestride/check.sh xfrc   # or build with -DNXF=k and write the slots after the mocap rows of ctrl.bin
```
